### Project Overview

This project analyzes data from the **T20 Cricket World Cup 2022** to identify the best-performing 11-player team using real-world statistics.

**Key Features:**
- **Web Scraping:** Extracted detailed player statistics from [ESPNcricinfo](https://www.espncricinfo.com) using **Bright Data**.
- **Data Cleaning:** Used **Pandas** to clean and process raw data.
- **Visualization:** Built an interactive **Power BI dashboard** to highlight insights like top scorers, strike rates, wicket-takers, and balanced team composition.
- **Team Analysis:** Assembled a data-backed "Best XI" squad for T20 matches.
